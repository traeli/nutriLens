# 食迹簿 UI 概念稿 V1

本轮以 `docs/city-dining-experience-prd.md` 为产品依据，暂用「食迹簿」作为品牌占位名。设计目标是把产品从营养分析工具转为可信、克制的城市餐饮体验记录产品，同时为旧版功能保留清晰但次要的入口。

## 页面清单

1. `01-discover.png`：发现首页
2. `02-search-filter.png`：初版搜索与筛选
3. `02-search-store-v2.png`：店名优先搜索（修订版，后续实现采用此稿）
4. `03-experience-detail.png`：体验详情
5. `04-create-record.png`：创建到店记录（第 1 步）
6. `05-review-status.png`：公开申请审核进度
7. `06-footprints.png`：足迹地图与最近记录
8. `07-profile.png`：我的
9. `08-legacy-tools.png`：旧版数据与工具

## 设计系统

- 背景：暖瓷白 `#F7F5F0`
- 主文字：近黑墨色 `#181816`
- 主强调：克制朱红 `#C84B31`
- 正向状态：苔绿 `#4F6B57`
- 风格：真实餐饮摄影、充足留白、细分割线、统一线性图标、16–24px 圆角、轻阴影
- 避免：AI 渐变、霓虹色、玻璃拟态、卡通吉祥物、无意义大卡片、过度胶囊按钮、廉价模板感

## 旧功能保留策略

旧版的 AI 食物分析、饮食历史、今天吃什么、我的菜品、积分、成就、连续打卡、排行榜和分享海报统一收纳到「我的 → 旧版数据与工具」。旧数据只对用户本人可见，不自动转为公开餐饮点评，也不参与新版内容推荐或可信度计算。

## 图像生成提示词摘要

所有页面均使用 `ui-mockup` 类型生成，要求：单张竖屏微信小程序高保真界面、无手机外框、接近高品质 iPhone 原生应用的克制与精密感但不复制系统应用；使用上述统一色彩和排版体系；中文文本清晰；避免渐变、玻璃拟态、模板化仪表盘和廉价阴影。每张图再分别补充对应页面的结构、字段、状态与精确中文文案。

这些图片是视觉方向稿，适合确认信息层级、气质和核心布局；进入开发前仍需据此整理可实现的组件规范、交互状态和多尺寸适配规则。
