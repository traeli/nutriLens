# 城市首页主图 AI 生成提示词

本文档用于批量生成食迹簿首页的城市专属主图。图片之间只统一尺寸、基础色调和真实感，不统一机位、焦段、天气与拍摄时间，避免出现“同一模板替换城市”的效果。

## 生成原则

- 每座城市使用不同机位、焦段、天气和时间。
- 不要求每张图片都出现著名地标，优先表现普通街角、社区、早餐店、坡道、树荫和通勤场景。
- 不使用固定 seed，每座城市重新随机生成。
- 首页文字可读性由界面渐变遮罩保证，不强迫所有图片在相同位置留白。
- 每张图片只表现一个真实场景，不拼接现实中无法同时出现的地标。
- 避免使用“杰作、8K、极致细节、电影级、梦幻光影、完美构图”等容易加重 AI 感的描述。

## 通用真实感后缀

将以下内容添加到每座城市的专属提示词之后：

```text
真实中国城市街头摄影，不是旅游宣传照，不是商业广告。画面像当地摄影师在散步时偶然拍到的真实瞬间，构图自然，不完全对称，允许轻微遮挡、轻微颗粒、普通天气和不完美光线。建筑、道路、植被、人物穿着和城市尺度符合现实。

普通行人只作为环境的一部分，不看镜头，不摆拍。店铺招牌可以存在，但应处于远处、侧面、遮挡或轻微虚焦状态，避免生成清晰错误文字。色彩自然克制，真实相机动态范围，不过度锐化，不使用夸张景深，不使用电影海报调色。

横向图片，比例16:9，适合移动端首页裁切，画面上下保留少量裁切空间。
```


## 推荐角度与焦段

| 城市类型 | 推荐角度或焦段 |
| --- | --- |
| 北京、南京、哈尔滨 | 70–85mm 长焦 |
| 广州、重庆、贵阳 | 24–28mm 广角 |
| 上海、苏州、泉州 | 门框、墙体或船只形成框景 |
| 深圳、郑州 | 天桥或楼梯的轻微高视角 |
| 成都、合肥、淄博 | 坐下后的低机位 |
| 杭州、厦门、宁波 | 隔着车窗、栏杆或船体拍摄 |
| 青岛、大理、西安 | 行走或骑行过程中的抓拍 |
| 长沙、洛阳 | 手持夜间或室内向室外拍摄 |

## 输出设置

- 生成比例：16:9。
- 建议生成尺寸：至少 1536×864。
- 项目落地尺寸：统一裁切为 1200×672。
- 输出格式：WebP 优先，也可使用质量约 82% 的 JPEG。
- 每座城市先生成 4–8 张，选择城市特征真实、构图自然的一张。
- 不使用固定 seed；若同一批次构图仍然相似，应进一步改变焦段、机位和前景遮挡，而不是只替换城市名称。
- 将专属提示词、通用真实感后缀和通用反向提示词一起提交给生成模型。
